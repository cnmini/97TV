# 云影院
AI开发的电视端云影院，适配安卓电视/机顶盒。

### 功能
✅ 影片分类浏览
✅ 电视端片名搜索
✅ 观看历史
✅ 多站点线路切换
✅ 设备授权管理
✅ 播放器（支持跳过片头片尾）
