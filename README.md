# 云影院
AI生成的安卓电视端云影院APP，适配电视盒子，支持多线路、搜索、观看历史、设备授权。

## ✨ 功能
- 影片分类浏览：电影、连续剧、综艺、动漫、短剧
- 电视端虚拟键盘搜索影片
- 观看历史记录
- 主站/分站多线路切换
- 设备授权有效期管理
- 影片详情 + 多片源选集播放
- 播放器支持跳过片头、片尾
